# Movie Industry Data Analysis

## Project Overview

This project explores movie industry data to identify patterns and relationships between movie characteristics and commercial performance. Using Python, I performed exploratory data analysis (EDA) to investigate gross revenue, production budgets, and production company performance.

## Objectives

- Explore and clean movie industry data.
- Investigate correlations between numerical variables.
- Compare production companies based on their mean gross revenue.
- Rank companies by average gross revenue.
- Visualise findings to identify patterns in movie industry performance.

## Tools and Technologies

- **Python** — data analysis and manipulation
- **Pandas** — data cleaning, grouping, aggregation, and ranking
- **Matplotlib** — data visualisation
- **Seaborn** — statistical charts and correlation heatmaps
- **Jupyter Notebook** — interactive analysis

## Analysis and Methodology

1. **Data preparation:** Inspected the dataset, handled missing values, and prepared variables for analysis.
2. **Exploratory data analysis:** Examined distributions and relationships between movie characteristics.
3. **Correlation analysis:** Used Pearson correlation to investigate linear relationships between numerical variables.
4. **Production company analysis:** Grouped movies by production company and calculated mean gross revenue and movie counts.
5. **Company ranking:** Ranked production companies by mean gross revenue and compared the highest-performing companies.
6. **Data visualisation:** Created charts to communicate patterns and support interpretation of the findings.

## Key Skills Demonstrated

- Data cleaning and preprocessing
- Exploratory data analysis
- Grouping and aggregation with Pandas
- Correlation analysis
- Ranking and comparative analysis
- Data visualisation
- Analytical thinking and interpretation

## Conclusion

This project demonstrates how Python can be used to explore movie industry data, assess relationships between variables, and compare production companies based on average gross revenue. It also highlights the importance of considering sample size when interpreting company performance.

*Note: Mean gross revenue measures average box-office revenue, not profit. Company rankings should be interpreted alongside the number of movies analysed for each company.*
